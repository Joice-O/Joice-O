## Projeto principal — TCC Sistema Free Flow

Meu **Trabalho de Conclusão de Curso** é o [Sistema Free Flow](https://github.com/Joice-O/SistemaFreeFlow), um protótipo acadêmico de cobrança automática de pedágio que integra **IoT, banco de dados e inteligência artificial**.

O sistema recebe eventos de ESP32 com leitores RFID, registra passagens, analisa duplicidades e anomalias com modelos Isolation Forest e gera cobranças. Possui interfaces separadas para clientes e concessionárias, com consulta de débitos, monitoramento de passagens e exportação de dados.

**Tecnologias presentes no projeto:** Python, FastAPI, SQLAlchemy, PostgreSQL, ESP32, RFID e Isolation Forest.

[Conheça o código e a documentação do TCC](https://github.com/Joice-O/SistemaFreeFlow).
